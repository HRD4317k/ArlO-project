Part 2: The Proposed Fully Unsupervised Method
2.1 Core Philosophical Shift
The fundamental insight that makes true unsupervised regime detection possible is this:

The degradation regime is not a label to be classified — it is a latent variable that governs the transition kernel of the MDP. Regime detection = identifying which transition kernel is currently active.

This reframes the problem from classification to transition kernel identification, which can be solved without any labels using the following principle:

Two transitions (s, a, s') and (s̃, ã, s̃') belong to the same regime if and only if a single dynamics model can predict both s' and s̃' with equal accuracy. They belong to different regimes if the model that predicts s' well predicts s̃' poorly, and vice versa.

This is the foundation of Regime-Contrastive Dynamics Prediction (RCDP) — the core of the proposed method.

2.2 The Full Method: Physics-Grounded Contrastive Regime Encoder (PGCRE)
The method has five components, each addressing a specific failure mode identified above:

Component 1: Multi-Scale Physics Residual Feature Vector (MSPRF)
Instead of a single ODE residual scalar, compute a vector of physics residuals that are each sensitive to δ through different physical channels. This vector becomes the self-supervised target that z_task must encode.
The five residuals:
R1 — Damping Excess Residual (from existing _ode_residual, kept):
$$r_1 = \frac{|\dot{\omega}{actual} - \dot{\omega}{healthy}|}{\omega} \approx \frac{1.5 \cdot \delta \cdot B}{J}$$
R2 — Power Efficiency Deficit (new):
$$r_2 = 1 - \frac{P_{out,t+1}}{\max(\omega_{t+1} \cdot T_{gen,t+1}, \epsilon)} \approx 0.35 \cdot \delta$$
This exploits eff_factor = 1 - 0.35*delta. The ratio P_out / (omega * T_gen) should be ~1.0 for a healthy turbine and drops linearly with δ.
R3 — Thermal Excess Rate (new):
$$r_3 = \frac{\Delta T_{bearing} - \Delta T_{bearing}^{healthy}}{\omega^2}$$
Where ΔT_bearing_healthy = (P_loss_baseline - h_conv*(T_bearing - 25)) / C_th * dt uses only the baseline P_loss = 0.02*(omega²+T_gen²)*1e6. The excess comes from P_friction = 0.015*delta*omega²*1e6, so:
$$r_3 \approx \frac{0.015 \cdot \delta \cdot \omega^2 \cdot 10^6}{\omega^2 \cdot C_{th}} = \frac{0.015 \cdot \delta \cdot 10^6}{C_{th}}$$
R4 — Vibration Variance Excess (new, computed over a rolling window):
$$r_4 = \text{Var}(\Delta\omega_{1:t}) - \text{Var}(\Delta\omega_{1:t})^{healthy}$$
The noise term in vibration is (0.1 + 0.4*delta)*N(0,1), so the variance of Δomega grows with δ. Over a window of W steps, this is estimable.
R5 — Maintenance Response Sensitivity (new):
$$r_5 = \mathbb{1}[a_{maint} > 0.7] \cdot r_1$$
When the maintenance action is active, degradation rate is multiplied by 0.1. The ODE residual should drop when maintenance is active in a degraded turbine but not in a healthy one. This cross-signal provides additional discriminative power.
The MSPRF vector: (\mathbf{r}_t = [r_1, r_2, r_3, r_4, r_5] \in \mathbb{R}^5)
Key property: Each r_i ≈ f_i(δ) — a monotone function of δ only, independent of omega, v_wind, T_gen (after normalization). This means r_t is a noise-reduced, physics-grounded proxy for the regime, computable from (s, a, s') without seeing delta.

Component 2: Regime-Contrastive Dynamics Prediction (RCDP)
This is the core training signal. It solves the fundamental problem identified in Experiment 6: naive contrastive learning learns temporal smoothness because negatives are drawn randomly and may be same-regime.
The key innovation: Use the MSPRF vector r_t to construct guaranteed cross-regime negatives without using true labels.
Algorithm:

Maintain a stratified transition buffer B = {B_low, B_mid, B_high} partitioned by the magnitude of r_1 (the most reliable residual):

B_low: r_1 < 0.375 (healthy, δ ∈ [0, 0.25])
B_mid: 0.375 ≤ r_1 < 0.75 (degrading, δ ∈ [0.25, 0.5])
B_high: r_1 ≥ 0.75 (critical/emergency, δ ∈ [0.5, 1.0])


For each training step with current transition τ_anchor = (s, a, r, s'):

Compute r_anchor = MSPRF(τ_anchor) → assign to stratum k
Sample positive τ_pos from same stratum k (same approximate regime)
Sample negative τ_neg from a different stratum k' ≠ k


Contrastive loss (InfoNCE-style):


$$\mathcal{L}{RCDP} = -\log \frac{\exp(\text{sim}(z{anchor}, z_{pos}) / \tau)}{\exp(\text{sim}(z_{anchor}, z_{pos}) / \tau) + \sum_{k'}\exp(\text{sim}(z_{anchor}, z_{neg,k'}) / \tau)}$$
Where sim(·,·) is cosine similarity and τ = 0.1 (sharp).
Why this works where Experiment 6 failed: The stratification by r_1 guarantees that negatives are from a genuinely different δ range. The MSPRF vector is computed analytically from physics — no labels needed. The contrastive loss then forces z_task to be discriminative across these strata, which correspond exactly to the four regimes.
Why this is truly unsupervised: The strata boundaries (0.375, 0.75) are derived from the physics equations, not from δ labels. They are thresholds on r_1 ≈ 1.5·δ·B/J, which is a function of observable quantities (omega, v_wind, T_gen, omega_next) only.

Component 3: MSPRF Regression with Monotone Constraint (MSPRF-Reg)
While RCDP provides the clustering structure, we need a continuous signal to prevent z_task from collapsing to a finite set of discrete points. The MSPRF regression loss provides this:
$$\mathcal{L}{reg} = \sum{i=1}^{5} w_i \cdot \text{MSE}(\hat{r}i(z{task}), r_i)$$
Where r̂_i(z_task) = fc_msprf_i(z_task) is a dedicated regression head for each residual.
Monotone constraint: Since each r_i is monotone in δ, and δ is monotone in the regime index, we can add a soft monotonicity regularizer:
$$\mathcal{L}{mono} = \sum{i=1}^{5} \max(0, \hat{r}i(z{task,t}) - \hat{r}i(z{task,t+1}) + \epsilon)$$
when the true r_i is increasing (which it is for all five residuals). This prevents the regression from learning a non-monotone mapping that could confuse regime ordering.
Weights: w = [2.0, 1.5, 1.0, 0.5, 0.5] — higher weight on r_1 (most reliable) and r_2 (second most reliable), lower on r_4, r_5 (noisier).

Component 4: Temporal Consistency Regularization (TCR)
Within a single episode, δ evolves slowly and monotonically (it only increases, except during maintenance). This gives us a free self-supervised signal:
$$\mathcal{L}{TCR} = \max(0, \text{sim}(z{task,t}, z_{task,t+\Delta}) - \text{sim}(z_{task,t}, z_{task,t-\Delta}))$$
This says: z_task at time t should be more similar to z_task at t-Δ (same or earlier regime) than to z_task at t+Δ (same or later regime, since δ only increases). This enforces temporal ordering of the latent space without labels.
Additionally, a smoothness loss prevents z_task from jumping erratically within a regime:
$$\mathcal{L}{smooth} = |z{task,t} - z_{task,t-1}|^2 \cdot \mathbb{1}[|r_{1,t} - r_{1,t-1}| < \epsilon_{stable}]$$
When the physics residual is stable (we're in the same regime), z_task should be stable too.

Component 5: Prototype-Anchored Clustering with Adaptive Sinkhorn (PAC-AS)
The SwAV implementation in the existing code fails because the temperature (0.5) is too high relative to the unit-sphere geometry, causing the logits to be too soft for Sinkhorn to produce meaningful assignments. The fix:
Adaptive temperature: Start with τ = 1.0 and anneal to τ = 0.05 over training. At τ = 1.0, Sinkhorn produces soft, balanced assignments that provide gradient everywhere. At τ = 0.05, assignments become sharp and prototype-anchored.
Prototype initialization from MSPRF: Instead of random prototype initialization, initialize prototypes using the first 100 episodes of MSPRF statistics:
# After 100 episodes, compute mean z_task per stratum
proto_low  = mean(z_task for transitions in B_low)
proto_mid  = mean(z_task for transitions in B_mid)
proto_high = mean(z_task for transitions in B_high)
# Split proto_high into two (critical vs emergency) using r_1 threshold 1.125

This gives physically meaningful prototype initialization that avoids the cold-start problem.
Modified SwAV loss:
$$\mathcal{L}{SwAV} = -\sum_k q_k \log p_k + \lambda{div} \cdot |P P^T - I|_F^2$$
Where q_k are Sinkhorn codes, p_k = softmax(z · proto_k / τ), and the diversity term prevents prototype collapse.

2.3 Delta Inference — Continuous Degradation Estimation
Once z_task is trained with the above losses, delta inference proceeds through three complementary estimators that are fused:
Estimator 1: MSPRF-Based Direct Estimate
Since r_1 ≈ 1.5·δ·B/J and we know B = 100, J = 1e6:
$$\hat{\delta}_{physics} = \frac{r_1 \cdot J}{1.5 \cdot B} = \frac{r_1 \cdot 10^6}{150} = \frac{r_1}{1.5 \times 10^{-4}}$$
After ω-normalization, r_1 ≈ 1.5·δ directly, so:
$$\hat{\delta}_{physics} = \frac{r_1}{1.5}$$
This is the most direct estimator. It requires no training — it's purely analytical. Its weakness is noise from wind variability and action effects.
Denoising: Average over the context window:
$$\hat{\delta}{physics} = \frac{1}{H}\sum{h=1}^{H} \frac{r_{1,h}}{1.5}$$
Estimator 2: Latent Distance Estimate
After training, the regime centroids {μ_0, μ_1, μ_2, μ_3} are positioned in z_task space. The distance from z_task to the healthy centroid μ_0 provides a continuous δ estimate:
$$\hat{\delta}{latent} = \frac{d(z{task}, \mu_0)}{d(\mu_3, \mu_0)}$$
Where d(·,·) is Euclidean distance. This normalizes by the maximum possible distance (healthy to emergency centroid), giving a value in [0, 1].
Improvement over existing infer_degradation_score(): The existing method uses cosine distance from centroid 0, which saturates quickly on the unit sphere. Euclidean distance in the normalized latent space provides better resolution across the full [0, 1] range.
Estimator 3: Learned Regression Head
The MSPRF regression head fc_msprf_1 predicts r_1 from z_task. Since r_1 ≈ 1.5·δ, we can invert:
$$\hat{\delta}_{learned} = \frac{\hat{r}1(z{task})}{1.5}$$
This estimator benefits from the full context window aggregation in z_task and is smoother than the per-step physics estimate.
Fusion
The three estimators are fused with uncertainty-weighted averaging:
$$\hat{\delta}{fused} = \frac{w_1 \hat{\delta}{physics} + w_2 \hat{\delta}{latent} + w_3 \hat{\delta}{learned}}{w_1 + w_2 + w_3}$$
Where:

w_1 = 1 / Var(r_1 over context window) — high weight when physics signal is stable
w_2 = confidence(regime_detection) — high weight when centroid assignment is confident
w_3 = 1.0 — fixed baseline weight for learned estimator

    τ_pos    ← sample from B_k (same stratum)
    τ_neg    ← sample from B_{k'}, k'≠k (different stratum)

    L_mono   ← monotonicity_penalty(r_pred)

    z_future ← z_task_buffer[t+Δ]    # detached (if available)
    L_TCR    ← temporal_ordering_loss(z_task, z_prev, z_future)
    L_smooth ← smoothness_loss(z_task, z_prev, r_vec)

    τ_swav   ← anneal(ep, 1.0, 0.05)
    L_SwAV   ← adaptive_swav(z_task, prototypes, τ_swav)
    
    # Loss 5: Weak KL (annealed)
    β        ← anneal(ep, 0.0, 0.0001)
    L_KL     ← β * kl_loss()
    
    # Total loss
    L_total  ← 3.0*L_RCDP + 5.0*L_reg + 0.5*L_mono 
              + 1.0*L_TCR + 0.2*L_smooth 
              + 0.5*L_SwAV + L_KL
    
    optimizer.zero_grad()
    L_total.backward()
    clip_grad_norm_(encoder.parameters(), 1.0)
    optimizer.step()
  
  PHASE 3 — Prototype Update (every 100 episodes):
    IF ep == 100:
      Initialize prototypes from stratum centroids
    ELSE:
      Update prototypes via EMA from current z_task assignments

    δ_latent   ← latent_distance_estimate(z_task, centroids)

def msprf_regression_loss(self, r_vec: np.ndarray) -> torch.Tensor:
    if self._last_mu is None:
        return torch.tensor(0.0, device=self.device)
    weights = torch.tensor([2.0, 1.5, 1.0, 0.5, 0.5], device=self.device)
    r_target = torch.FloatTensor(r_vec).to(self.device)
    r_pred = torch.cat([head(self._last_mu) for head in self.fc_msprf], dim=-1)
    return (weights * F.mse_loss(r_pred, r_target, reduction='none')).mean()

# New method: Temporal consistency loss
def temporal_consistency_loss(self, z_current, delta_t=10) -> torch.Tensor:
    if len(self.z_task_history) < delta_t + 1:
        return torch.tensor(0.0, device=self.device)
    z_past = self.z_task_history[-delta_t]  # detached
    sim_past = F.cosine_similarity(z_current.unsqueeze(0), 
                                    z_past.unsqueeze(0))
    # z_current should be more similar to z_past than to random
    # (since delta only increases, z_task should drift slowly)
    return F.relu(0.5 - sim_past)  # penalize if similarity < 0.5

2.7 Validation Without Labels
Since we cannot use true labels for validation in the unsupervised setting, use these three metrics:

Physics-Silhouette Score: Compute silhouette score using MSPRF vector as the ground-truth distance metric (not regime labels). High silhouette = z_task clusters align with physics residual clusters.

Delta Reconstruction Error: Compare δ_fused against r_1 / 1.5 (the physics estimate). Since r_1 is computed from observables only, this is a label-free quality metric.

Temporal Monotonicity Score: Within each episode, compute the fraction of steps where ||z_task_t - μ_0|| ≤ ||z_task_{t+1} - μ_0|| (z_task moves away from healthy centroid over time). Should be > 0.7 for a well-trained encoder.
