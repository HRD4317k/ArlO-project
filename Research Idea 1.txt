Heterogeneous Multi-Agent RL with Dynamic Reward & Transfer LearningIndustrial Use Case: Predictive Maintenance & Adaptive Control of a Wind Turbine FarmProblem StatementA wind turbine farm has multiple turbines, each subject to:* Varying wind conditions (non-stationary environment)* Mechanical degradation (bearings, gearbox, blades)* Electrical grid constraints* Safety regulationsGoal: Learn an adaptive control & maintenance policy that:* Maximizes energy output * Minimizes unplanned downtime * Extends component life (RUL-aware) * Respects physics constraints (torque, RPM limits) * Adapts to new turbine types with minimal retraining A single RL agent fails here because: early training is data-sparse, physics are complex, and the reward landscape shifts with degradation stage.Full System Architecture????????????????????????????????????????????????????????????????????????? Preliminaries & Notation1.1 Markov Decision Process (MDP) FoundationWe define the environment as an augmented MDP:$$\mathcal{M} = \langle \mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma, \mathcal{K}, \mathcal{F} \rangle$$Where:SymbolDefinition(\mathcal{S} \subseteq \mathbb{R}^n)Continuous state space(\mathcal{A} \subseteq \mathbb{R}^m)Continuous action space(\mathcal{P}: \mathcal{S} \times \mathcal{A} \times \mathcal{S} \rightarrow [0,1])Transition probability kernel(\mathcal{R}: \mathcal{S} \times \mathcal{A} \times \mathcal{S} \rightarrow \mathbb{R})Dynamic reward function(\gamma \in [0,1))Discount factor(\mathcal{K})Set of physical constraint operators(\mathcal{F})Foundation model semantic prior1.2 State Vector DefinitionThe state at time (t) is:$$s_t = \left[ \underbrace{x_t^{sensor}}{\text{sensor readings}}, \underbrace{x_t^{deg}}{\text{degradation index}}, \underbrace{x_t^{env}}{\text{environment}}, \underbrace{x_t^{grid}}{\text{grid demand}} \right]^T \in \mathbb{R}^n$$1.3 Agent SetDefine the heterogeneous agent pool:$$\mathcal{G} = {A_1, A_2, A_3, A_4}$$Where:$$A_k = \langle \pi_k, \phi_k, \Theta_k, \mathcal{U}_k \rangle$$* (\pi_k: \mathcal{S} \rightarrow \Delta(\mathcal{A})) — policy (distribution over actions)* (\phi_k: \mathcal{S} \rightarrow \mathbb{R}^d) — state encoder* (\Theta_k) — learnable parameters* (\mathcal{U}_k: \mathcal{S} \rightarrow \mathbb{R}^+) — uncertainty estimator2. Shared Latent Embedding Space2.1 Individual EncodersEach agent encodes the state into its own latent representation:$$z_k^t = \phi_k(s_t; \Theta_k^{enc}), \quad z_k^t \in \mathbb{R}^{d_k}$$2.2 Cross-Agent AlignmentA learnable alignment function maps all agent embeddings into a unified shared space (\mathbb{R}^d):$$z_{shared}^t = \mathcal{A}{align}\left(z_1^t, z_2^t, z_3^t, z_4^t; \Theta{align}\right)$$Implemented as an attention-weighted aggregation:$$z_{shared}^t = \sum_{k=1}^{4} \alpha_k^t \cdot W_k z_k^t$$Where attention weights (\alpha_k^t) are:$$\alpha_k^t = \frac{\exp\left(e_k^T z_k^t / \sqrt{d}\right)}{\sum_{j=1}^{4} \exp\left(e_j^T z_j^t / \sqrt{d}\right)}$$And (e_k \in \mathbb{R}^d) are learnable agent-specific query vectors.2.3 Alignment LossTo enforce semantic consistency across agent embeddings:$$\mathcal{L}{align} = \sum{k=1}^{4} \sum_{j \neq k} \left| W_k z_k^t - W_j z_j^t \right|2^2 + \lambda{orth} \sum_{k=1}^{4} \left| W_k^T W_k - I \right|_F^2$$Where the second term enforces orthogonality of projection matrices to preserve agent-specific information.3. Agent Formulations3.1 Agent 1 — Deep RL Agent (SAC)Policy: Stochastic Gaussian policy:$$\pi_1(a_t | s_t, z_{shared}^t) = \mathcal{N}\left(\mu_{\Theta_1}(s_t, z_{shared}^t),\ \Sigma_{\Theta_1}(s_t, z_{shared}^t)\right)$$Objective (Maximum Entropy RL):$$J(\pi_1) = \mathbb{E}{\tau \sim \pi_1}\left[\sum{t=0}^{T} \gamma^t \left(r_t + \alpha \mathcal{H}\left(\pi_1(\cdot | s_t, z_{shared}^t)\right)\right)\right]$$Where entropy (\mathcal{H}(\pi_1) = -\mathbb{E}_{a \sim \pi_1}[\log \pi_1(a|s_t)])Critic (Q-function):$$Q_{\Theta_1}(s_t, a_t) = \mathbb{E}\left[\sum_{l=0}^{\infty} \gamma^l \left(r_{t+l} + \alpha \mathcal{H}(\pi_1(\cdot|s_{t+l}))\right)\right]$$SAC Update:$$\mathcal{L}{critic} = \mathbb{E}\left[\left(Q{\Theta_1}(s_t, a_t) - \left(r_t + \gamma \bar{Q}(s_{t+1}, \tilde{a}{t+1}) - \alpha \log \pi_1(\tilde{a}{t+1}|s_{t+1})\right)\right)^2\right]$$$$\mathcal{L}{actor} = \mathbb{E}\left[\alpha \log \pi_1(a_t|s_t) - Q{\Theta_1}(s_t, a_t)\right]$$3.2 Agent 2 — Bayesian Agent (Gaussian Process)GP Prior over the Q-function:$$Q_{GP}(s, a) \sim \mathcal{GP}\left(\mu_0(s,a),\ k\left((s,a),(s',a')\right)\right)$$Using a Matérn 5/2 kernel:$$k(x, x') = \sigma_f^2 \left(1 + \frac{\sqrt{5}|x - x'|}{l} + \frac{5|x-x'|^2}{3l^2}\right) \exp\left(-\frac{\sqrt{5}|x-x'|}{l}\right)$$Posterior given observations (\mathcal{D}t = {(s_i, a_i, r_i)}{i=1}^t):$$\mu_{GP}(s,a|\mathcal{D}_t) = \mu_0 + \mathbf{k}^T(K + \sigma_n^2 I)^{-1}(\mathbf{r} - \mu_0)$$$$\sigma^2_{GP}(s,a|\mathcal{D}_t) = k(x,x) - \mathbf{k}^T(K + \sigma_n^2 I)^{-1}\mathbf{k}$$RUL Posterior (Hidden Markov Model over degradation states):$$p(RUL_t | s_{1:t}) = \sum_{d \in \mathcal{D}} p(RUL_t | d_t) \cdot p(d_t | s_{1:t})$$Where (d_t) is the latent degradation state and:$$p(d_t | s_{1:t}) \propto p(s_t | d_t) \sum_{d_{t-1}} p(d_t | d_{t-1}) p(d_{t-1} | s_{1:t-1})$$Epistemic Uncertainty (used for exploration bonus):$$\mathcal{U}2(s_t) = \sigma^2{GP}(s_t, \pi_1(s_t) | \mathcal{D}_t)$$3.3 Agent 3 — Foundation Model AgentSemantic State Mapping:$$\tilde{s}_t = \mathcal{T}(s_t): \mathbb{R}^n \rightarrow \mathcal{V}^*$$Where (\mathcal{T}) is a structured text template and (\mathcal{V}^*) is the token vocabulary space.FM Policy (via in-context reasoning):$$\pi_3(a_t, \mathbf{w}_t | \tilde{s}t) = p{FM}\left(a_t, \mathbf{w}_t \mid \tilde{s}t, \mathcal{C}{context}\right)$$Where (\mathbf{w}t = [w_1(t), ..., w_5(t)]^T) are the suggested reward weights and (\mathcal{C}{context}) is the in-context prompt history.FM Reward Weight Output (softmax-normalized):$$\mathbf{w}_t^{FM} = \text{softmax}\left(\text{FM_score}(r_1, ..., r_5 | \tilde{s}_t)\right)$$Semantic Embedding (from FM hidden states):$$z_3^t = \text{FM_embed}(\tilde{s}t) \in \mathbb{R}^{d{FM}}$$Projected into shared space via:$$\hat{z}3^t = W_3 z_3^t, \quad W_3 \in \mathbb{R}^{d \times d{FM}}$$3.4 Agent 4 — Physics / PINN AgentTurbine Dynamics (ODE System):$$\frac{d\omega}{dt} = \frac{1}{J}\left(T_{aero}(\lambda, \beta) - T_{gen} - B\omega\right)$$$$\frac{dT}{dt} = \frac{1}{C_{th}}\left(P_{loss}(\omega, T_{gen}) - h(T - T_{amb})\right)$$$$\frac{d\delta}{dt} = f_{deg}(\omega, T, F_{vib})$$Where:* (\omega) = rotor angular velocity* (T) = bearing temperature* (\delta) = degradation index* (\lambda = \frac{\omega R}{v_{wind}}) = tip-speed ratio* (\beta) = blade pitch angle (control input)* (C_{th}) = thermal capacitance* (f_{deg}) = degradation rate functionAerodynamic Torque:$$T_{aero}(\lambda, \beta) = \frac{1}{2} \rho \pi R^3 v_{wind}^2 C_Q(\lambda, \beta)$$Where (C_Q(\lambda, \beta)) is the torque coefficient from blade element momentum theory.PINN Loss:$$\mathcal{L}{PINN} = \underbrace{\frac{1}{N}\sum{i=1}^N |f(s_i) - \hat{f}(s_i;\Theta_4)|2^2}{\mathcal{L}{data}} + \underbrace{\lambda_1 \left|\frac{d\hat{\omega}}{dt} - \frac{1}{J}(T{aero} - T_{gen} - B\hat{\omega})\right|2^2}{\mathcal{L}{ODE}} + \underbrace{\lambda_2 \mathcal{L}{BC}}_{\text{boundary conditions}}$$Safe Action Bounds (from physics constraints):$$\mathcal{C}{safe}(s_t) = \left{a \in \mathcal{A} : \omega{min} \leq \omega(s_t, a) \leq \omega_{max},\ T(s_t,a) \leq T_{max},\ \delta(s_t,a) \leq \delta_{crit}\right}$$Physics Policy:$$\pi_4(a_t | s_t) = \arg\min_{a \in \mathcal{C}{safe}(s_t)} \mathcal{L}{PINN}(s_t, a)$$4. Meta-Controller / Arbiter4.1 Competence ScoreFor each agent (k), define the competence score at state (s_t):$$c_k(s_t) = \eta \cdot \bar{R}_k(s_t) - (1-\eta) \cdot \mathcal{U}_k(s_t)$$Where:* (\bar{R}_k(s_t)) = exponential moving average of reward under agent (k)'s policy in region of (s_t)* (\mathcal{U}_k(s_t)) = uncertainty of agent (k) at (s_t)* (\eta \in [0,1]) = competence-uncertainty trade-off4.2 Gating NetworkThe gating network (G_\Theta: \mathcal{S} \rightarrow \Delta^4) (probability simplex over 4 agents):$$g_k(s_t) = \frac{\exp\left(G_\Theta^{(k)}(s_t) / \tau\right)}{\sum_{j=1}^{4} \exp\left(G_\Theta^{(j)}(s_t) / \tau\right)}$$Where (\tau > 0) is a temperature parameter controlling sharpness of selection.4.3 Composite Action$$a_t = \Pi_{\mathcal{C}{safe}}\left(\sum{k=1}^{4} g_k(s_t) \cdot a_k^t\right)$$Where (\Pi_{\mathcal{C}_{safe}}) is the projection onto the safe action set:$$\Pi_{\mathcal{C}{safe}}(a) = \arg\min{a' \in \mathcal{C}_{safe}(s_t)} |a - a'|_2^2$$4.4 Arbiter UpdateThe gating network is updated via policy gradient on the composite reward:$$\nabla_\Theta \mathcal{L}{arbiter} = -\mathbb{E}\left[\sum{k=1}^{4} \nabla_\Theta \log g_k(s_t) \cdot \left(Q_{composite}(s_t, a_t) - b(s_t)\right)\right]$$Where (b(s_t)) is a baseline (value function) to reduce variance.5. Dynamic Reward Function5.1 Composite Reward$$r_t = \boldsymbol{w}(t)^T \boldsymbol{r}(s_t, a_t, s_{t+1})$$Where:$$\boldsymbol{r} = \begin{pmatrix} r_{energy} \ r_{RUL} \ r_{safety} \ r_{physics} \ r_{curiosity} \end{pmatrix}, \quad \boldsymbol{w}(t) = \begin{pmatrix} w_1(t) \ w_2(t) \ w_3(t) \ w_4(t) \ w_5(t) \end{pmatrix}, \quad \sum_{k=1}^5 w_k(t) = 1$$5.2 Individual Reward ComponentsEnergy Reward:$$r_{energy}(s_t, a_t) = \frac{P(s_t, a_t)}{P_{rated}} \in [0, 1]$$RUL Preservation Reward:$$r_{RUL}(s_t) = 1 - \exp\left(-\alpha \cdot \mathbb{E}[RUL_t | s_{1:t}]\right)$$Where (\mathbb{E}[RUL_t | s_{1:t}]) is the posterior mean from Agent 2.Safety Reward (indicator + soft penalty):$$r_{safety}(s_t, a_t) = -\mathbb{1}\left[a_t \notin \mathcal{C}{safe}(s_t)\right] - \mu \cdot d\left(a_t, \mathcal{C}{safe}(s_t)\right)$$Where (d(a_t, \mathcal{C}_{safe})) is the distance to the safe set boundary.Physics Residual Reward:$$r_{physics}(s_t, a_t) = -\left|\frac{d\hat{f}}{dt}(s_t, a_t) - f_{ODE}(s_t, a_t)\right|_2^2$$Curiosity / Exploration Reward:$$r_{curiosity}(s_t) = \beta \cdot \mathcal{U}_2(s_t) \cdot \mathbb{1}\left[\mathcal{U}2(s_t) > \epsilon{thresh}\right]$$5.3 Dynamic Weight UpdateWeights evolve via a coupled ODE system driven by training phase (\psi_t), degradation index (\delta_t), and FM suggestion (\mathbf{w}_t^{FM}):$$\frac{d\boldsymbol{w}}{dt} = -\nabla_{\boldsymbol{w}} \mathcal{L}_{weight}(\boldsymbol{w}, \psi_t, \delta_t) + \kappa \left(\mathbf{w}_t^{FM} - \boldsymbol{w}(t)\right)$$Where:$$\mathcal{L}{weight} = -\mathbb{E}\left[Q{composite}(s_t, a_t)\right] + \lambda_{entropy} \mathcal{H}(\boldsymbol{w})$$The entropy term (\mathcal{H}(\boldsymbol{w}) = -\sum_k w_k \log w_k) prevents reward collapse (all weight on one component).The FM pull term (\kappa(\mathbf{w}_t^{FM} - \boldsymbol{w}(t))) allows the Foundation Model to steer reward priorities during anomalies.6. Bidirectional Transfer Learning Framework6.1 Unified Transfer Loss$$\mathcal{L}{transfer} = \mathcal{L}{P \rightarrow N} + \mathcal{L}{N \rightarrow G} + \mathcal{L}{G \rightarrow N} + \mathcal{L}{N \rightarrow P} + \mathcal{L}{FM \rightarrow All}$$6.2 Transfer ?: Physics ? NN (Constraint Regularization)$$\mathcal{L}{P \rightarrow N} = \lambda{PN} \underbrace{\left|\frac{d\hat{f}{NN}}{dt} - f{ODE}\right|2^2}{\text{ODE residual}} + \mu_{PN} \underbrace{\max\left(0,\ \pi_1(s_t) - a_{max}(s_t)\right)^2}_{\text{constraint violation}}$$This forces the NN agent's predicted dynamics to be consistent with physics.6.3 Transfer ?: NN ? GP (Policy Distillation)$$\mathcal{L}{N \rightarrow G} = \lambda{NG} \cdot \mathbb{KL}\left(\pi_1(\cdot | s_t) | \pi_2(\cdot | s_t)\right)$$$$= \lambda_{NG} \int_{\mathcal{A}} \pi_1(a|s_t) \log \frac{\pi_1(a|s_t)}{\pi_2(a|s_t)} da$$The GP agent is updated to track the NN policy in high-confidence regions, improving sample efficiency of the Bayesian model.6.4 Transfer ?: GP ? NN (Uncertainty-Guided Exploration)The GP uncertainty map modifies the NN agent's exploration strategy via an augmented objective:$$J_{augmented}(\pi_1) = J(\pi_1) + \beta \cdot \mathbb{E}{s_t \sim \rho{\pi_1}}\left[\mathcal{U}_2(s_t)\right]$$And the GP uncertainty is injected as an intrinsic reward:$$\mathcal{L}_{G \rightarrow N} = -\beta \cdot \mathbb{E}\left[\mathcal{U}_2(s_t) \cdot \mathbb{1}[\mathcal{U}_2(s_t) > \epsilon]\right]$$6.5 Transfer ?: NN ? Physics (Residual Correction)The physics model is corrected by a residual neural network (f_{res}):$$\hat{f}{corrected}(s_t, a_t) = f{ODE}(s_t, a_t) + f_{res}(s_t, a_t; \Theta_{res})$$The residual network is trained on the NN agent's experience:$$\mathcal{L}{N \rightarrow P} = \frac{1}{|\mathcal{D}|} \sum{(s,a,s') \in \mathcal{D}} \left|s' - \hat{f}_{corrected}(s, a)\right|_2^2$$This allows the physics model to adapt its parameters from real data while maintaining physical interpretability.6.6 Transfer ?: FM ? All (Semantic Prior Injection)The Foundation Model contributes a semantic embedding prior to the shared latent space:$$\mathcal{L}{FM \rightarrow All} = \lambda{FM} \sum_{k=1}^{4} \left|z_k^t - \hat{z}_3^t\right|2^2 \cdot \mathbb{1}\left[\text{FM_confidence}(s_t) > \theta{FM}\right]$$This is conditionally activated — FM embeddings only influence other agents when the FM's confidence exceeds threshold (\theta_{FM}), preventing hallucination propagation.6.7 Total Agent LossFor the NN agent (Agent 1), the full training objective is:$$\mathcal{L}{total}^{(1)} = \underbrace{\mathcal{L}{SAC}}{\text{RL objective}} + \underbrace{\mathcal{L}{P \rightarrow N}}{\text{physics regularization}} + \underbrace{\mathcal{L}{G \rightarrow N}}{\text{uncertainty exploration}} + \underbrace{\lambda{align} \mathcal{L}{align}}{\text{embedding alignment}}$$7. Theoretical Properties7.1 Convergence GuaranteeTheorem 1 (Convergence of Composite Policy):Under the following conditions:1. Each individual policy (\pi_k) satisfies the Lipschitz condition: (|\pi_k(s) - \pi_k(s')| \leq L_k |s - s'|)2. The gating network (G_\Theta) is continuously differentiable3. The reward function (r_t) is bounded: (r_t \in [r_{min}, r_{max}])The composite policy (\pi_{composite} = \sum_k g_k \pi_k) converges to a local Nash equilibrium of the multi-agent objective:$$\pi^* = \arg\max_{\pi_{composite}} \mathbb{E}\left[\sum_{t=0}^{T} \gamma^t r_t\right]$$With convergence rate:$$\left|J(\pi^*) - J(\pi_t)\right| \leq \mathcal{O}\left(\frac{1}{\sqrt{t}}\right)$$7.2 Safety GuaranteeTheorem 2 (Physics Constraint Satisfaction):If the projection operator (\Pi_{\mathcal{C}_{safe}}) is applied at every timestep, then:$$\mathbb{P}\left(a_t \in \mathcal{C}_{safe}(s_t)\ \forall t\right) = 1$$Furthermore, the expected physics residual is bounded:$$\mathbb{E}\left[\left|\frac{d\hat{f}}{dt} - f_{ODE}\right|2^2\right] \leq \frac{\mathcal{L}{P \rightarrow N}}{\lambda_{PN}}$$7.3 Transfer Learning BenefitTheorem 3 (Sample Complexity Reduction):Let (N_{single}) be the number of samples required for a single RL agent to achieve (\epsilon)-optimal policy. With physics transfer, the NN agent achieves the same (\epsilon)-optimality with:$$N_{HMARL} \leq N_{single} \cdot \left(1 - \rho_{physics}\right)$$Where (\rho_{physics} \in [0,1]) is the physics informativeness ratio:$$\rho_{physics} = 1 - \frac{\mathcal{H}(\pi_1 | \pi_4)}{\mathcal{H}(\pi_1)}$$Higher physics informativeness ? fewer samples needed for the NN agent.7.4 Reward Non-Collapse ConditionProposition 1: The dynamic reward weight vector (\boldsymbol{w}(t)) does not collapse to a degenerate solution (all weight on one component) if and only if:$$\lambda_{entropy} > \max_k \left|\frac{\partial \mathbb{E}[Q_{composite}]}{\partial w_k}\right|$$This gives a practical condition for tuning the entropy regularization coefficient.8. Complete Objective SummaryThe full system objective is:$$\max_{\Theta_1, \Theta_2, \Theta_{align}, \Theta_{arbiter}, \boldsymbol{w}} \mathcal{J}_{HMARL}$$$$\mathcal{J}{HMARL} = \underbrace{\mathbb{E}{\tau \sim \pi_{composite}}\left[\sum_{t=0}^{T} \gamma^t \boldsymbol{w}(t)^T \boldsymbol{r}t\right]}{\text{composite RL objective}} + \underbrace{\alpha \sum_{k=1}^{4} \mathcal{H}(\pi_k)}{\text{entropy regularization}} - \underbrace{\mathcal{L}{transfer}}{\text{transfer losses}} - \underbrace{\lambda{align} \mathcal{L}{align}}{\text{embedding alignment}}$$Subject to:$$a_t \in \mathcal{C}_{safe}(s_t) \quad \forall t \qquad \text{(physics safety)}$$$$\sum_{k=1}^{5} w_k(t) = 1,\ w_k(t) \geq 0 \quad \forall t \qquad \text{(reward simplex)}$$$$\sum_{k=1}^{4} g_k(s_t) = 1,\ g_k(s_t) \geq 0 \quad \forall t \qquad \text{(gating simplex)}$$9. Main training script3.2 Core Modules — Full Implementationcore/embedding.py — Shared Latent Spaceimport torchimport torch.nn as nnimport torch.nn.functional as Ffrom typing import Listclass AgentEncoder(nn.Module):    """Individual encoder for each agent."""    def __init__(self, input_dim: int, latent_dim: int):        super().__init__()        self.net = nn.Sequential(            nn.Linear(input_dim, 128),            nn.LayerNorm(128),            nn.ReLU(),            nn.Linear(128, latent_dim),            nn.LayerNorm(latent_dim)        )    def forward(self, x: torch.Tensor) -> torch.Tensor:        return self.net(x)class SharedEmbeddingSpace(nn.Module):    """    Attention-weighted aggregation of heterogeneous    agent embeddings into a unified shared space.    z_shared = ? ?_k · W_k · z_k    """    def __init__(        self,        agent_dims: List[int],        shared_dim: int,        n_agents: int = 4    ):        super().__init__()        self.n_agents   = n_agents        self.shared_dim = shared_dim        # Projection matrices W_k for each agent        self.projections = nn.ModuleList([            nn.Linear(dim, shared_dim, bias=False)            for dim in agent_dims        ])        # Learnable query vectors e_k        self.query_vectors = nn.Parameter(            torch.randn(n_agents, shared_dim)        )        # Layer norm for stability        self.layer_norm = nn.LayerNorm(shared_dim)    def forward(        self,        embeddings: List[torch.Tensor]    ) -> tuple[torch.Tensor, torch.Tensor]:        """        Args:            embeddings: List of [batch, d_k] tensors        Returns:            z_shared: [batch, shared_dim]            alpha:    [batch, n_agents] attention weights        """        # Project each embedding to shared space        projected = [            self.projections[k](embeddings[k])            for k in range(self.n_agents)        ]  # List of [batch, shared_dim]        # Stack: [batch, n_agents, shared_dim]        stacked = torch.stack(projected, dim=1)        # Compute attention scores        # queries: [n_agents, shared_dim]        scores = torch.einsum(            'bkd,kd->bk',            stacked,            self.query_vectors        ) / (self.shared_dim ** 0.5)  # z_FM||?                   · 1[conf > ?_FM]        """        if fm_confidence < self.fm_thresh:            return torch.tensor(0.0)        loss = torch.tensor(0.0)        for k, z_k in embeddings.items():            if k != 'fm':                loss += F.mse_loss(z_k, fm_embedding)        return self.lambda_fm * loss    def compute_total_transfer_loss(        self, all_losses: Dict[str, torch.Tensor]    ) -> torch.Tensor:        """L_transfer = ? all transfer losses."""        return sum(all_losses.values())train.py — Main Training Loopimport torchimport numpy as npimport yamlfrom agents.sac_agent    import SACAgentfrom agents.pinn_agent   import PINNAgentfrom agents.gp_agent     import GPAgentfrom agents.fm_agent     import FMAgentfrom core.embedding      import SharedEmbeddingSpacefrom core.arbiter        import Arbiterfrom core.reward_shaper  import DynamicRewardShaperfrom core.transfer_hub   import TransferLearningHubfrom utils.replay_buffer import ReplayBufferfrom utils.logger        import Loggerfrom utils.metrics       import MetricsTrackerdef train(config_path: str = 'configs/wind_config.yaml'):    # ??
